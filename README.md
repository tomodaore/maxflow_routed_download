## 作品概要

ファイルサーバーからクライアントへファイルを転送する際に、複数の中継サーバー間の通信帯域を計測し、その結果をもとに転送経路を決定することを目的として制作しました。

クライアント側では主に、

1. ファイルサイズを取得
2. 中継サーバーとの通信帯域を計測
3. 各中継サーバーからサーバー間の帯域情報を収集
4. 帯域情報からグラフを作成
5. Edmonds-Karp法を用いて最大フローと経路を計算
6. ファイル受信処理と経路計算を並行して実行

という処理を行います。

中継サーバー側では、クライアントや他の中継サーバーからの要求を受け取り、帯域測定用データの送信、他ノードへの帯域測定、通信の中継などを行います。

## 実行環境・実行方法

このプログラムは、単体のPCだけで完結するアプリケーションではなく、複数のホストが存在するネットワーク環境を前提としています。

### 中継サーバー

各中継サーバーで、

```bash
python3 relay_main.py
```

を実行します。

`relay_main.py` は実行したホスト名を取得し、コード内の `NODE_MAP` に対応するポートで待ち受けます。

現在のコードでは、中継サーバーとして `pg1` ～ `pg14` が定義され、ポート `54300` を使用します。

### クライアント

クライアント側は次の形式で実行します。

```bash
python3 client.py <server_host> <server_port> <filename> <token>
```

- `server_host`：転送対象ファイルを保持するサーバー
- `server_port`：ファイルサーバーの待受ポート
- `filename`：取得するファイル名
- `token`：鍵生成に使用するトークン

実際の動作には、

- `pgs.txt` に記載された中継サーバー
- 各中継サーバーで動作する `relay_main.py`
- `pbl2.py`
- 転送対象ファイルを保持し、SIZE / GET / REP 等の要求を処理するファイルサーバー

が必要です。

このため、一般的なPC1台で簡単に動作確認する形式ではなく、複数ホストを使用した制作環境を前提とした作品です。
